## 使用范围

本项目是 CodeBuddy 与 WorkBuddy 的非官方 OpenAI 兼容网关，与目标平台没有隶属或授权关系。

仅允许在以下范围内使用：

- 使用本人持有并已授权的账号。
- 在本机或受控私有网络中运行。
- 遵守目标平台服务条款和所在地法律。
- 自行承担账号、数据和网络暴露产生的风险。

禁止：

- 共享、出售或公开分发他人账号和凭证。
- 将本项目用于绕过平台限制、牟利或违法用途。
- 将管理面板、调用接口或明文凭证暴露给未授权用户。

## 凭据安全

以下文件包含敏感信息：

- `auths/`：账号 token 和身份信息。
- `keys.json`：调用密钥。
- `config.json`：可能包含 `api_key`、管理 token 和 Upstash token。

建议：

- 文件权限设置为 `0600`。
- 不把运行目录提交到 Git。
- 公网部署必须设置强随机 `api_key`。
- 定期运行 `wbapi doctor` 检查权限和服务状态。

## 发布完整性

GitHub Release 同时提供平台压缩包和 `SHA256SUMS`。下载后应校验 SHA-256，再解压运行。

Go 二进制由当前源码构建。重新构建 Web 管理面板时还需要 Node，但运行时不依赖 Node。`go.sum` 只约束 Go 模块依赖，不校验自定义构建产物。
